# Syazwan Aqim — Information Systems Portfolio

A responsive digital portfolio built with HTML, CSS and vanilla JavaScript.

## Features

- Cinematic particle loader
- Responsive navigation
- Dark and light themes
- Interactive Home knowledge core
- About journey and hanging identity card
- Skills orbit with filters and details
- Project gallery with popup image slider
- Certificate vault
- Digital badge gallery
- Contact form that prepares a `mailto:` message
- Desktop and mobile layouts
- Reduced-motion support

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D
- Google Fonts
- Simple Icons CDN
