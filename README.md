# Syazwan Aqim Portfolio — Module 03: Ultra Home Experience

This is a **complete project snapshot**. It already contains the working cinematic loader from Module 02.6 and the upgraded homepage.

## What was added

### Cinematic homepage
- Animated recruiter-focused headline entrance
- Live role-text scrambling
- Interactive hero particle network
- Mouse-reactive spotlight and depth
- 3D-style knowledge core rendered with Canvas
- Rotating network globe and orbital capability labels
- Floating glass information panels
- Live system telemetry
- Magnetic call-to-action buttons
- Custom desktop cursor
- Responsive mobile layout
- Reduced-motion accessibility support

### Navigation
- Animated floating navigation
- Active-section indicator
- Mobile navigation panel
- Animated light/dark theme transformation
- Saved theme preference

### Easy updates
Edit:

`data/home.js`

to change:
- Degree
- Graduation year
- Rotating roles
- Hero description
- Highlight facts
- Orbit labels

Edit:

`data/config.js`

to change the loader name and loader settings.

## Run

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Run `index.html` with Live Server.
4. Press `Ctrl + Shift + R` once if the browser shows a cached older version.
